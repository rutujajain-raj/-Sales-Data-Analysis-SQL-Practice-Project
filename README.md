📊 Sales Data Analysis & SQL Practice Project

This project is designed to help students practice Data Cleaning, Data Analysis, and SQL queries using a real-world sales dataset.

The dataset contains multiple related tables with 250 records each, simulating an actual business sales environment. Students will clean the data in Excel, import it into MySQL, and perform analysis using SQL.

📁 Dataset Includes

The Excel file contains the following sheets:

1. Customers

Customer details

City, State, Email

Contains missing values for cleaning practice

2. Products

Product information

Category & Price

3. Orders

Order details

Order date & status

4. Order_Items (Sales Table)

Quantity sold

Discount

Total amount

Includes some missing/dirty values

🎯 Learning Objectives

Students will learn:

Data Cleaning in Excel

Handling missing values

Data formatting (dates, numbers)

CSV export & database import

SQL queries (SELECT, WHERE, JOIN, GROUP BY, HAVING)

Business insights from sales data

🛠 Tools Required

Microsoft Excel / Google Sheets

MySQL Workbench

SQL

📌 Tasks to Perform
Step 1 – Data Cleaning

Remove blank rows

Fix missing values

Correct formats

Save each sheet as CSV

Step 2 – Database

Create tables in MySQL

Import CSV files

Step 3 – SQL Practice

Solve the provided SQL questions:

Basic queries

Joins

Aggregations

Grouping

Subqueries

Sales analysis

📈 Sample Analysis Questions

Total sales revenue

Top selling products

Customer-wise sales

Category-wise revenue

Customers with no orders

✅ Outcome

By completing this project, students will gain hands-on experience with real-world data analytics workflows used in industry.
